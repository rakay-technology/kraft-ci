# kraft-ci

Public CI/CD compute for a **private** repository.

Public repositories get unlimited GitHub Actions minutes; private ones get a
small, exhaustible allowance. So the builds, tests and image jobs run **here**,
where the minutes are free.

This repository holds **workflows only**. No source, no releases, no installers,
no images — everything produced lands on the private side.

Open **Actions** to run a workflow.
